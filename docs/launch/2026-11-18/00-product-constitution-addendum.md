# Product Constitution Addendum 2026-11-18
## SourceRating AI-native Cross-Organization Workroom

**Version:** 4.0  
**Effective Date:** 2026-11-18  
**Owner Direction:** Chat naturally. AI works silently. Decisions become traceable.  
**Execution Lead:** AGY (Antigravity) via T3 Code

---

### 1. 核心宪法原则

1. **真正内核是聊天（Chat-First Core）**
   - SourceRating 不是 AI 客服插件、不是纯工程采购 SaaS、不是企业黄页、不是极客式 Agent 俱乐部。
   - 核心是像原生即时通讯一样可靠、清爽、低学习成本、能承载真实企业间协作的 AI-native messaging。

2. **真实工作优先（Real Work First）**
   - 用户可以只发消息、传图纸、问 AI、查看翻译、确认版本；不需要了解 Agent、MCP 或 A2A 概念。
   - AI 是随手可用的静默辅助能力，默认安静，绝不抢夺主流程；即使 AI 模型宕机或超时，原生聊天与文件传输绝对正常运行。

3. **产品底座通用，冷启动垂直（Universal Base, Vertical Cold-Start）**
   - 第一阶段从工程、预制构件、国际采购、专业检测/工程服务的真实跨企业双边关系切入。
   - 通讯基础数据结构保持通用扩展性，不把底层对象硬编码绑定为“预制管桩询价流程”。

4. **嵌入式工作流与单一后端（Embedded Workstream & Single Authority）**
   - Precast.World 的产品/企业/工程项目页面可直接调起即时沟通，简单咨询原地完成；需要多方、长周期沟通时升级到同一 SourceRating Room，保留完整上下文与授权资料。
   - **绝对禁止在 Precast.World 另建第二套独立聊天后端**。

5. **Marketplace、Network、Discover 是 Work 的自然延伸**
   - 严禁另起传统 B2B 网站或无依据的自动评分系统。
   - 企业、人员、产品的真实档案在跨企业授权协作中逐步沉淀、核验，UI 设计突出少文字、重图片/能力/证据；**严禁泄露竞争供应商的私有报价与采购内幕**。

6. **Agent 原生扩展契约，暂缓自治群聊**
   - 保留清晰的 Actor/Agent 身份、权限隔离与可审计工具调用契约。
   - 第三方 Agent 网络、Agent 市场、大规模全自治群聊在 Release A 阶段暂缓。

7. **确定性动作与人类确认优先（Human Commit First）**
   - 简单确认、直接编辑、结构化报价/审批均由人类通过明确的点击动作完成。
   - AI 可从消息、图纸、Excel 自动预填和提出建议，但**AI 绝不能自主确认报价、合同、付款或工程签核，必须经过 Human Commit**。

8. **完整产品骨架先具备，再进行市场试验**
   - 绝不拿残缺 Demo 试验用户；但完整不等于第一版重造 Office、CAD、ERP 或视频会议，专业能力优先集成成熟成熟组件。
